# METHOD setting 提问式实验教程

日期：2026-07-20  
目的：帮助读者用实验问题驱动的方式判断某个 setting 是否值得跑。  
说明：本文件保留教学结构，但统一成汇报风格。

---

## 1. bg

很多 setting 失败，不是因为“命令写错”，而是没有先判断这个设置在当前代码里是否完整、稳定、可验证。

## 2. Objective

在动手前先回答：

1. 这个 setting 改了什么。
2. 当前仓库是否已经实现它。
3. 它的主要风险在哪。

## 3. Experimental Setup

### 3.1 统一判断流程

1. 读方法定义。
2. 查代码缺口。
3. 做 smoke。
4. 做短训练。
5. 再决定是否上正式实验。

## 4. Results

这个流程对 ComEmbed 和 Engram 都同样有效。

## 5. Conclusion

不要把 setting 当成一个命令，而要把它当成一个完整实验假设。
