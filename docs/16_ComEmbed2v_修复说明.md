# ComEmbed 2v 修复与运行说明

日期：2026-07-20  
目的：说明 ComEmbed 2v 稳定化修复背后的操作逻辑。  
说明：本文件记录的是修复过程，不直接代表最终结果优劣。

---

## 1. bg

2v 失败后，问题转向“如何让它先稳定跑起来”，而不是直接追求更强结果。

## 2. Objective

修复目标包括：

1. 控制数值范围。
2. 避免异常梯度污染优化器。
3. 保留尽可能多的有效梯度更新。

## 3. Experimental Setup

### 3.1 主要修复方向

- 乘法路径前后做 norm。
- 减小注入强度并加 warmup。
- 清洗局部非有限梯度。

## 4. Results

这些修复证明 2v 的问题集中在数值稳定性，而不是结构完全不可行。

## 5. Conclusion

修复文档的作用是解释“为什么这样改”，不是替代正式实验报告。
