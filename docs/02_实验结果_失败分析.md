# 实验结果与失败分析

日期：2026-07-20  
目的：汇总 `Baseline / X-gram / Engram / ComEmbed` 的关键结果与典型失败原因。  
说明：本文件只保留对后续判断仍有价值的失败经验。

---

## 1. bg

历史问题主要不是“代码不能跑”，而是“实验口径不一致”或“数值稳定性不足”。

## 2. Objective

本文件回答：

1. 哪些结果能作为正式对照。
2. 哪些早期结论后来被推翻。
3. 失败主要发生在哪些层面。

## 3. Experimental Setup

### 3.1 已确认失败类型

| 类型 | 典型问题 |
|:--|:--|
| 口径错误 | Engram backbone 被冻结，导致实验不公平 |
| 日志误读 | 用不完整或旧 warmup 日志解读最终结果 |
| 数值不稳 | ComEmbed 2v 在 backward 后出现 `NaN/Inf` |
| 资源限制 | 完整大规模 Engram 在当前硬件上 OOM |

## 4. Results

- `Baseline / X-gram` 的终点下游结果是完整可用的。
- `Engram` 旧版错误实验不能再引用为正式结果。
- `Engram faircompare` 压缩版是当前可用正式口径。
- `ComEmbed 2v` 失败原因已经定位到数值稳定性，而不是数据或调度问题。

## 5. Conclusion

后续任何报告都必须先说明所用结果属于哪条实验线、哪一版口径。
